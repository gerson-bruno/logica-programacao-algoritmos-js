## 🎯 Objetivo

Consolidar fundamentos de programação através da resolução prática de exercícios, com foco em:

- Estrutura lógica
- Resolução de problemas
- Boas práticas com JavaScript
- Evolução contínua como desenvolvedor

/Capitulo-03 - Exercício 3

Cada pasta contém:
- Exercícios resolvidos
- Código limpo e organizado
- Evolução progressiva da lógica
